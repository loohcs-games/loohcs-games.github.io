# Loohcs高等学院ゲーム大全

開発ゼミで作ったゲームを集めて公開するサイト。
公開ページ: https://loohcs-games.github.io/

## 仕組み

- `index.html` がトップページ。`games.js` の一覧を読んでカードを並べる
- ゲームは `games/<id>/index.html` に1本ずつ置く。`<id>` は作った人の GitHub ユーザー名（2本目からは `ユーザー名-2` のように）
- `main` に取り込まれると、数分で公開ページが更新される（GitHub Pages）
- ビルドは要らない。ブラウザで `index.html` を開けば手元でも見られる

## 載せ方

[howto.md](howto.md) を読む。

## ルール

1. 本名、メールアドレス、学校の住所、PC のフォルダ名をファイルに書かない。作者名は GitHub のユーザー名
2. 他人が作った画像・音・コードは、作った人が使ってよいと言っているもの以外は入れない
3. 自分のフォルダ（`games/<自分のid>/`）と、`games.js` の自分の枠だけを直す。他の人のフォルダは、本人に声をかけてから
4. 送る前に、自分で一度遊んで確かめる
5. `main` には直接送らない。ブランチを作って Pull Request を出し、先生が取り込む
